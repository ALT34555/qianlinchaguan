# 第三方资源与参考清单

## 运行时依赖

无第三方运行库。`qianlinchaguan.exe` 仅链接 Windows 自带组件：

| 组件 | 用途 |
| :--- | :--- |
| `USER32` / `GDI32` / `IMM32` | 窗口、消息、文字烘焙与输入法 |
| `OPENGL32` | OpenGL 3.3 Core 渲染 |
| `ole32` + `windowscodecs` | COM 入口与 WIC 图片解码（PNG） |
| `KERNEL32` / `ADVAPI32` | 文件、时钟与系统信息 |

C 运行时静态链接（`/MT`），不需要 VC++ 运行库；不使用 .NET、Node.js、Electron 或 WebView。

## 字体（可选外置 Mod，不随仓库分发）

程序启动与设置页「重新扫描」时枚举 `userdata/mods/fonts/`，未放置字体时回退系统字体。

- Resource Han Rounded（资源圆体）— SIL OFL 1.1 — <https://github.com/CyanoHao/Resource-Han-Rounded>
- NanoOldSong（纳米老宋）— SIL OFL 1.1 — <https://github.com/Hansha2011/NanoOldSong>
- LXGW WenKai（霞鹜文楷）— SIL OFL 1.1 — <https://github.com/lxgw/LxgwWenKai>

## 语言包（可选外置 Mod）

`userdata/mods/l10n/ja/` 为日语示例包，格式见该目录 `README.md`；词条由本项目自行翻译。内置中文与英文不依赖外置文件。

## 算法与数据参考

- 世界生成、湖岸与岛形、海岸模板、植物与岩石形态、冰与冻融模型：全部由本项目程序化生成；`content/` 下只有参数表，没有外部模型或贴图。
- 历法：公历 / 农历 / 元历三历并轨，定朔与置闰规则按中国天文年历实现。
- ΔT 分段多项式：Espenak & Meeus / NASA 日食目录 — <https://eclipse.gsfc.nasa.gov/SEcat5/deltatpoly.html>
- 天体位置与食相级数：参考 astronomia（MIT）的实现思路 — <https://github.com/commenthol/astronomia>
- 界面配色：OKLab 空间色混合，语义对齐 CSS Color Module Level 4 的 `color-mix()`。
- 世界规则与视觉标杆：同项目 Web/TypeScript 基准版（0.2.0 及更早版本存于本仓库 Git 历史）。
