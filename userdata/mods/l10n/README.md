# 外置语言包

每种语言使用一个目录。内置简体中文、英文和繁体中文随主程序发布，不依赖这里的文件。

```text
l10n/
  ja/
    manifest.json       语言标识和显示名称
    ui.json             界面及内容翻译
    names/
      flags.json        置旗地自动命名
      people.json       人物命名占位，当前为 {}
```

把语言包放在 `userdata/mods/l10n` 的子目录中。每个语言包需要 `manifest.json`，并至少提供 `ui.json` 或 `names/flags.json`。

## manifest.json

```json
{
  "schemaVersion": 1,
  "code": "ja",
  "label": "日本語",
  "nameFallback": "en"
}
```

- `code` 是稳定的语言标识，建议与目录名相同。可使用 ASCII 字母、数字、连字符和下划线，最多 31 字节。匹配时忽略大小写，并将下划线视为连字符。已注册的区域语言优先于它的语言前缀。内置 `zh-CN`、`en`、`zh-Hant` 的标识保留。
- `label` 是设置页和文化选项的显示名称。
- `nameFallback` 选填，可用 `en`、`zh-CN` 或 `zh-Hant`，默认 `en`。它用于回退缺失的命名词条。

目录名可以使用 Unicode。所有 JSON 文件使用 UTF-8，可以带 BOM。文件内不能包含 NUL 字节。

## UI 与命名分别装载

在 `ui.json` 中使用平面的字符串键值对象，例如 `{"nav.home":"表紙"}`。已有词条缺失、值为空或格式不匹配时，界面使用内置简体中文文案。

带格式参数的词条须保留参数的类型、个数和顺序，例如原文中的 `%s`、`%d` 和 `%.1f`。字段宽度和精度可使用最多三位数字。格式词条中的百分号写成 `%%`，普通文案中的百分号直接写成 `%`。扫描语言包时会检查格式词条。

`names/people.json` 目前保留空对象 `{}`。

## names/flags.json

命名词条使用独立的平面对象。

- `format` 是置旗地模板，须包含 `{climate}` 和 `{terrain}` 两个占位符。
- `climate.1` 至 `climate.5` 对应常年冰封、寒带、温带、亚热带、热带。
- `terrain.<材质>.<形态>` 的材质编号 0 至 5 对应承托物、岩、土壤、盐碱土壤、沙、砾。形态编号 1 至 5 对应平坦、凹地、隆起、陡峭、雕刻。
- `fallback.0` 至 `fallback.3` 提供类型未知、无效或模板无法展开时的通用自动名。
- `leader.format` 可使用 `{place}` 插入地名。`leader.strip` 可先去掉地名末尾指定的文字。

下例包含部分词条。

```json
{
  "format": "{climate}{terrain}の地",
  "climate.2": "寒冷な",
  "terrain.4.1": "砂原",
  "fallback.0": "遠野の地",
  "fallback.1": "初見の地",
  "fallback.2": "新垣の地",
  "fallback.3": "未名の地"
}
```

[日文命名词表](ja/names/flags.json)可作为新语言的起点。命名模板的占位符使用花括号。
非空命名表会把该语言加入文化选择和混合文化候选。混合按阵营 ID 确定性选择一种候选文化，不混拼不同语言的词。

文化默认取新建世界时的当前语言。自动名在创建时生成，并连同具体文化写入存档。
切换界面语言、更新或移除语言包不会修改已保存的地名；新生成阵营才会使用当前可用词表。
显式自定义名称优先于自动名；类型无效时使用通用自动名。
