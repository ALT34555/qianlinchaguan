# 世界方块与地质数据

自然水体是独立连续水位/种类/速度/来水场（DynamicWater），不填入水方块。ID8「静态水方块」用于临界雪线小洼地（同时可能生成冰31），并供内容和未来建筑使用。雪线上方常年封冻；雪线下64格临界带不生成河流。当前没有单方块编辑；区块水力边界是未来建筑/坝体的生成接口，完整蓄水传播与模拟尚未实现。

通用ID为0～35（含空气）。专用ID = 三位区块地质代码 × 100 + 两位专用编号01～03，00保留。数字存储去掉前导零，展示用code补成五位；例如00101整数101，热带山丘10301为砾岩。地表及Worker传输使用Uint32，覆盖全部五位编码。每类0～3种，本版45种可生成区块共90种；虚空不设置专用方块。

字段：key唯一；color为sRGB颜色；filler是表层下的通用填充材料；base是植被等旧接口使用的基础语义（例如砾岩归stone）；category用于地质露头适配；erodibility/permeability为0～1相对参数。侵蚀性参与风化微地势，渗透性暂为后续水文扩展保留。专用材料参与地质混合权重和最终列抽样，区块之间连续混合。
