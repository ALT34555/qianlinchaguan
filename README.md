##  关于项目

**《茜林茶馆》** 是一套以中式古典美学为基底、完全由随机种子生成的沙盒世界。玩家在二维**「舆图」**与三维**「山川」**之间自由流转：俯瞰大陆、空降漫步、开渠改河、观星问历。

本仓库是它的 **C11 原生实现**：一个 Win32 窗口 + 自建即时模式 UI + OpenGL 3.3 Core，整份游戏编译成单个 `qianlinchaguan.exe`。没有 .NET、没有 Node、没有 Electron、没有 WebView，Windows 版只链接系统组件，解压即玩。

同源的 **Web / TypeScript 基准版**仍在并行开发，作为生成算法与视觉表现的对照标杆；本版与其逐项对齐：同样的世界规则、同样的界面语言、同样的操作手感。

> 本仓库自 `0.3.0` 起为 C11 原生版；此前的 Web 版（`0.2.0` 及更早）可在 Git 历史与 `v0.2.0` 标签中查看。

##  下载与运行

0.3.1 同时提供 Windows x64 压缩包与 Android arm64 APK。安卓要求 Android 10 及以上、OpenGL ES 3.0；下载安装 `茜林茶馆_0.3.1_Android.apk`。安卓通过系统文件选择器导出存档，应用数据保存在应用专属目录。

1. 在 [**Releases**](https://github.com/ALT34555/qianlinchaguan/releases) 下载 `茜林茶馆_0.3.1_Windows.zip`；
2. 解压到任意目录（路径可含中文与空格，无需管理员权限）；
3. 双击 `qianlinchaguan.exe`。

首次运行会在 exe 同级创建 `userdata/`：

```text
userdata/
├── saves/        五槽存档（*.sav）
├── exports/      导出副本
├── settings.bin  设置、键位、视距与触控布局
└── mods/
    ├── fonts/    可选：放入 ttf/otf 后在设置页「重新扫描」
    └── l10n/     可选：外置语言包（随包附日语示例）
```

**系统要求**：Windows 10 / 11 x64；显卡驱动需支持 OpenGL 3.3 Core（近十年的独显与集显均可）。程序不写注册表、不装服务，所有数据都留在游戏目录内。

##  特性亮点

###  舆图 × 山川，同一世界的两种看法

- **三种投影**：球面 3D、等距矩形、墨卡托，单 Pass 着色器实时切换。
- **12 个可调图层**：领地、区块、经纬基线、日照、雨云、等高线、气候、温度、高程、冰、水深、装饰支流与泉眼，各自独立开关与不透明度。
- **等高线 L4–L24**：L4–L15 保留基准档位，L16–L24 逐级减半细化到 0.125m，放大看山脊不糊。
- **河宽高精度裁剪**：高倍放大时河道按地表真实曲线与宽度逐段视口裁剪，河口与湖岸自然接平。
- **无缝空降**：在舆图上双击任意地块即可落到该处三维山川，随时按 `M` 往返。

###  两种世界：星球与无限

- **星球模式**：一次性生成球面宏观格——板块漂移与碰撞、构造带山脉、风带降水、源流水系与湖盆聚类，再逐级细化。
- **无限模式**：100×100 宏观块分片平铺，相邻片以 1m 隔离海过渡；越过隔离海中线后按主种子与片坐标哈希确定性生成邻片并平移坐标，边缘海深无缝拼合，无经度折返、无极点畸变。
- **3D 山川**：32m×32m 区块连续展开，4–32 区块圆形视距由近及远挂载与释放；雾距随视距与天气能见度线性收放。

###  统一流域水系

- 严格下降 D8 拓扑 + 实际汇水累加求解，消除局部凹陷死循环；支流汇聚时主槽深度与河宽随流量平滑增长。
- 自然三段河弯与走廊约束，入湖/入海低缓渐宽，水下沉积浅滩与沙泥渐变，瀑布入水保留深潭。
- 天然分阶瀑布、跌水岩壁切面与飞流水丝、落点水雾粒子。
- **自由画河**：`/world.river craft` 进入交互式画河道，左键拖拽连续笔画、自动去重与自交闭环清理，按两端地势判定流向并开槽；人工河整河稳定 ID、跨宏观格链式分段，未接主河时自动闭合成末端小湖。

###  126 物种 · 3,402 种组合

- 六类（草 `cao` / 灌 `guan` / 花 `hua` / 农 `nong` / 乔 `shu` / 水 `shui`）独立建模，四季、幼体与各档网格全部由参数表程序化生成，不依赖外部模型。
- 13 个植物 tag 族（4 项环境耐受、积水耐受、固着性等）与 1–5 单值基质编码，统一适宜度加权选种。
- 植被密度 0–9 十档平滑扩展：草/灌/水生候选按倍率递增，高档保留低档已有植被。
- 远景走四季贴图交叉面片与 billboard，18 区块外不塌陷；区块流式装载时限频重建。

###  岩石与地貌

- 64 种自然散布岩石（小/中/大/巨石四档），五种基质 × 三种气候常数加权生成率与风化度，全部支持朝上雪片挂点。
- 8 种高 18–52m 的谷地超巨岩、8 种高 32–58m 的贴合崖壁岩，配六套岩性色板并按地壳构造场自适应赋色。
- 8 种石林拼块，标准正八边形接面，支持 45° 阶梯堆叠成山。

###  海岸、湖岸与岛形

- 6 组 97×97 海岸模板（湾、岬、泥洲、离岸沙洲、陡岸、残礁），浅水与底色读取模板材质权重，泥滩浑浊、沙滩清澈、岩岸骤深。
- 湖泊套用 24 种预制轮廓、14 种湖床与河流连接段，湖心岛按 7 套岛形逐宏观格抽签，格边界内收并淡出。
- 深海孤立格套用 20 种岛形模板，3D 与舆图共用同一高度采样。
- 2m 地形网格的水平面与冰面按 2cm 干湿等值线裁切，岸边波浪随屏幕水深自适应衰减。

###  湖河冻融

- 由绝对气候日经一阶热滞后得到水体有效温度，再用冷暖度日积分求冰厚与冰质：浅湾、近岸、小水面先冻，深水与大湖晚冻，春季先腐后化。
- 冰厚与承重分离：新薄冰脆，化冻旧冰即使较厚也弱。悬空单元可被踩碎、跳碎或落地击穿，破洞同时撤掉渲染与碰撞，人会真的落水；破洞状态随存档持久化，重新从 0 结冰。
- 浮冰与碎冰共用固定实例池，不承重、不加载区块。

###  天气与降水

- 25 档天气、风速 0–5 驱动植物与旗帜摆动；晴天与雾天各有独立的雾距曲线。
- 逐日降水场推进水汽、季节雨热与雨日判定，3D 天气与舆图雨云雷达共用同一场数据。
- 植物按基准温度与稳定哈希正态错峰换季（±15 日），同一物种不在同一天集体变色。

###  天文与天象

- 十五颗轨道星体、星座与星云，日月按世界时间、地理与黄赤交角运动。
- 公历 / 农历（定朔置闰）/ 元历三历并轨，观星舆图显示日食偏全环食区与月食可见区。
- 流星、流星雨、周期彗星与日月食按确定性窗口生成，`/world.astra events` 查看预报。

###  存档与界面

- **五槽存档**：1 快速 + 3 手动 + 1 自动，单文件世界容器（`QLCG` v1，槽体 v13），兼容读取 v11 单档；手动槽可显式指定、可改名、可复制为「悠游」副本。
- **即时模式 UI**：所有控件压进同一顶点批次，一次 `glDrawArrays` 画完；文字经 GDI 烘焙到图集，只取 alpha 着色，换主题不必重烘。
- **OKLab 动态配色**：41 个颜色令牌运行时计算，`color-mix(in oklab, …)` 等价实现，自动按 WCAG 对比度下限压深文字色；主色可由玩家衣冠色接管，日/夜两套随系统切换。
- **中 / 英 / 日**：全部界面文本与逻辑解耦，语言包外置于 `userdata/mods/l10n/`。

##  操作说明

| 操作 | 动作 |
| :--- | :--- |
| **W / A / S / D** | 行走；飞行时为水平移动 |
| **鼠标** | 转动视角（点击画面锁定指针） |
| **空格** | 跳跃；**快速双击**切换飞行 / 浮空 |
| **Shift** | 疾跑；飞行时加速 |
| **Ctrl** | 蹲下；飞行时下降 |
| **M** | 舆图 ↔ 山川 切换 |
| **鼠标双击**（舆图） | 空降到该地块，直接进入 3D 山川 |
| **L** | 舆图图层面板（悠游模式） |
| **1 – 5** | 工程工具：空手 / 铲除 / 造林 / 河道 / 填海（悠游模式） |
| **Ctrl+Z** | 撤销上一次工程编辑 |
| **Ctrl+P** | 快速存档 |
| **`/` 或 `Enter`** | 打开命令条，`/help` 列出全部命令 |
| **F12** | 调试浮层：鹰眼小地图、气候、区块与帧率 |
| **Esc** | 暂停 / 菜单 / 释放指针 |

>  **触屏**：设置 → 「屏幕虚拟按键」开启摇杆与动作键，可调透明度与四项落位；键位映射在设置页可逐项重绑，冲突会自动交换。

常用命令示例：

```text
/world.river craft      交互式画河道
/world.weather 101      强制切换天气档位（000–902）
/world.astra            开关观星辅助
/world.astra events     查看未来天象
/time.speed 60          调整时间流速
/calendar.              历法与节气查询
```

##  从源码构建

Android：安装 JDK 17、Python 3、Gradle 8.11.1、Android SDK 35、NDK 28.2.13676358 与 CMake 3.22.1，设置 `ANDROID_HOME` 后运行 `powershell -ExecutionPolicy Bypass -File build_android.ps1`。默认生成未签名 Release APK，需要使用自己的 Android 发布密钥签署。密钥不随仓库分发。

**环境**：Windows 10 / 11 x64；Visual Studio 2022 或 2026（安装「使用 C++ 的桌面开发」工作负载）。无第三方依赖，无需包管理器。

```bat
build.bat
```

脚本会自动定位 `vcvars64.bat`、编译 `src/` 下 270 个 `.c`、编译 `app.rc` 图标资源，链接 8 个系统库，最终在仓库根目录产出 `qianlinchaguan.exe`，中间产物写入 `obj/`。

编译选项为 `/O2 /fp:precise /std:c11 /utf-8 /W3 /MT`：静态链接 C 运行时，产出单文件绿色程序。

> `build.bat` 按常见安装路径查找 Visual Studio；若安装位置特殊，请在脚本 `:find_vcvars` 段手动指定 `vcvars64.bat`。

│   ├── terrain3d/     3D 山川：区块网格、地形与水体着色、雨云、远景贴图
│   └── ui/            即时模式 UI：控件、主题令牌、文字编辑器、页面与浮层

│   ├── assets/ui/     界面图集来源（图标、按钮底盘、装饰）
│   └── data/world/    参数表（植物、岩石、崖壁、石林、移动、碰撞边界）

> 说明：本仓库是从开发工程按发布规范导出的纯净版本，不含内部开发工具、规格文档与回归脚本；`src/systems/world/model/` 下的四季贴图既是源码树的一部分，也是运行时远景贴图资源。

##  存档与设置

| 项目 | 格式 | 说明 |
| :--- | :--- | :--- |
| 世界容器 | `QLCG` v1 | 一个 `.sav` 内含 5 个槽位 |
| 槽体 | v12 | 多片 `PLN1`、自由河道 `RIV1` v2、冰 `ICE1`、降水 `RAIN1`；兼容读取 v11 单档 |
| 存档命名 | `save_{世界名}_{HHMMSS}_{seed}.sav` | 世界名随历法与语言切换 |
| 设置 | `QLCGSTG5` | 键位、视距、植被密度、触控布局、配色偏好 |
| 地形 | v4 | 旧地形字段在采样时重算 |

世界规则版本随存档写入，不兼容的旧档会被拒绝而不是错读；存档改名只改容器名，槽体逐字节不变。

##  常见问题

**启动黑屏 / 提示显卡不支持？**
程序要求 OpenGL 3.3 Core。请更新显卡驱动；远程桌面与部分虚拟机不提供该上下文。

**界面缺字或字形不对？**
把任意中文 `ttf/otf` 放入 `userdata/mods/fonts/`，在设置页点「重新扫描」，无需重启。

**存档在哪、能否备份？**
`userdata/saves/`。整个 `userdata/` 目录就是全部玩家数据，复制即备份。

**为什么发布包里还有 `src/` 目录？**
`src/systems/world/model/` 下的四季贴图是运行时远景贴图资源，保留原相对路径可让发布包与源码树保持一致，直接构建即可运行。
