##  关于项目

**《茜林茶馆》** 是一套以中式古典美学为基底、完全由随机种子生成的沙盒世界。玩家在二维**「舆图」**与三维**「山川」**之间自由流转：俯瞰大陆、空降漫步、开渠改河、观星问历。

本仓库是它的 **C11 原生实现**：Windows 使用 Win32 + OpenGL 3.3 Core，Android 使用 GameActivity + OpenGL ES 3.0，共享世界生成、游戏逻辑与即时模式 UI。Windows 版编译为 `qianlinchaguan.exe`，与资源目录一起分发，只链接系统组件，无需 .NET、Node、Electron 或 WebView。

同源的 **Web / TypeScript 基准版**为世界生成和视觉表现提供参考。

> 本仓库自 `0.3.0` 起为 C11 原生版；此前的 Web 版（`0.2.0` 及更早）可在 Git 历史与 `v0.2.0` 标签中查看。

**源码说明更新于 2026-11-21。** 产品版本号沿用 `0.3.1`。已发布的安装包早于本文所述的源码，体验下列玩法及存档更新请[从源码构建](#从源码构建)。

##  下载与运行

0.3.1 同时提供 Windows x64 压缩包与 Android arm64 APK。安卓要求 Android 10 及以上、OpenGL ES 3.0；下载安装 `QLCG_0.3.1_Android.apk`。安卓通过系统文件选择器导入与导出存档，应用数据保存在应用专属目录。

1. 在 [**Releases**](https://github.com/ALT34555/qianlinchaguan/releases/tag/V0.3.1) 下载 `QLCG_0.3.1_Windows.zip`；
2. 解压到任意目录（路径可含中文与空格，无需管理员权限）；
3. 双击 `qianlinchaguan.exe`。

首次运行会在 exe 同级创建 `userdata/`：

```text
userdata/
├── saves/        五槽存档（*.sav）
├── exports/      导出副本
├── settings.bin  设置、键位、视距与触控布局
└── mods/
    ├── fonts/    可选：放入 ttf/otf 后在设置页「重新扫描」
    └── l10n/     可选：外置语言包（随包附日语示例）
```

**系统要求**：Windows 10 / 11 x64；显卡驱动需支持 OpenGL 3.3 Core。玩家数据保存在游戏目录内。Windows 渲染设备偏好由系统按程序路径保存，重启游戏后生效。

##  特性亮点

###  舆图 × 山川，同一世界的两种看法

- **三种投影**：球面 3D、等距矩形、墨卡托，单 Pass 着色器实时切换。
- **13 个可调图层**：领地、区块、经纬基线、日照、雨云、等高线、气候、温度、高程、冰、水深、装饰支流与泉眼、植被，各自独立开关与不透明度。
- **等高线 L4–L24**：L4–L15 保留基准档位，L16–L24 逐级减半细化到 0.125m，放大看山脊不糊。
- **河宽高精度裁剪**：高倍放大时河道按地表真实曲线与宽度逐段视口裁剪，河口与湖岸自然接平。
- **无缝空降**：在舆图上双击任意地块即可落到该处三维山川，随时按 `M` 往返。
- **植被舆图**：远中景显示当地植物丛的主乔木，放大后过渡到真实丛中心与散生乔木；四季图标随当地气候换季，湖面过滤与界面倍率共同控制显示密度，生存模式遵循探索范围。

###  两种世界：星球与无限

- **星球模式**：一次性生成球面宏观格——板块漂移与碰撞、构造带山脉、风带降水、源流水系与湖盆聚类，再逐级细化。
- **无限模式**：100×100 宏观块分片平铺，相邻片以 1m 隔离海过渡；越过隔离海中线后按主种子与片坐标哈希确定性生成邻片并平移坐标，边缘海深无缝拼合，无经度折返、无极点畸变。
- **3D 山川**：32m×32m 区块连续展开，4–32 区块圆形视距由近及远挂载与释放；雾距随视距与天气能见度线性收放。

###  画卷风格与增强光影

- **画卷风格**：青绿、浅绛、水墨三套设色，可调设色浓淡、墨色与线宽；山脊、植物与地表以勾线、晕染和留白呈现，地表材质在相邻区块间自然渗色，视距边缘渐隐为纸色。
- **增强光影**：提供日照阴影、水面反射与空间云表现；夜间关闭地平线以下的太阳直射，天气与季风共同影响云层。
- 在设置页选择视觉效果；两种风格使用同一套世界与地形数据。

###  统一流域水系

- 严格下降 D8 拓扑 + 实际汇水累加求解，消除局部凹陷死循环；支流汇聚时主槽深度与河宽随流量平滑增长。
- 自然三段河弯与走廊约束，入湖/入海低缓渐宽，水下沉积浅滩与沙泥渐变，瀑布入水保留深潭。
- 天然分阶瀑布、跌水岩壁切面与飞流水丝、落点水雾粒子。
- 主河、源流、河源、湖盆与岸坡共用水文断面与采样规则，河源起伏、汇流衔接和河谷地形保持连续。
- **自由画河**：`/world.river craft` 进入交互式画河道，左键拖拽连续笔画、自动去重与自交闭环清理，按两端地势判定流向并开槽；人工河整河稳定 ID、跨宏观格链式分段，未接主河时自动闭合成末端小湖。

###  153 个植物条目 · 九类模型

- 草、灌、花、农、乔、水、药、藤、菌九类，含 21 种农作物、12 种花卉和 8 个沿岸水生条目。四季、不同生长状态与显示档位按品种配置。
- 13 个植物 tag 族（4 项环境耐受、积水耐受、固着性等）与 1–5 单值基质编码，统一适宜度加权选种。
- **共生植物丛**：依据 20 类气候区生成混生丛与优势丛，混生丛由主乔木搭配共生灌木，优势丛保持单一乔木；草本与水生植物独立散布。
- 植被密度 0–9 十档平滑扩展：草/灌/水生候选按倍率递增，高档保留低档已有植被。
- 远景走四季贴图交叉面片与 billboard，18 区块外不塌陷；区块流式装载时限频重建。

###  行囊、领地与人偶

- **行囊与主副手**：装备工具采集木材、石料和纤维，翻土、种树苗或布置工作台。装备背包可扩展随身容量。
- **领地与聚落**：悠游模式启用人工地物后，可在山川中与旗帜互动，管理领地内的建造和开垦。聚落人口、产出与资源随世界时间推进，可在文明面板查看。
- **山川视角**：设置中可选择第一人称、越肩和第三人称。靠近人偶后可以互动。

###  岩石与地貌

- 64 种自然散布岩石（小/中/大/巨石四档），五种基质 × 三种气候常数加权生成率与风化度，全部支持朝上雪片挂点。
- 8 种高 18–52m 的谷地超巨岩、8 种高 32–58m 的贴合崖壁岩，配六套岩性色板并按地壳构造场自适应赋色。
- 8 种石林拼块，标准正八边形接面，支持 45° 阶梯堆叠成山。

###  海岸、湖岸与岛形

- 6 组 97×97 海岸模板（湾、岬、泥洲、离岸沙洲、陡岸、残礁），浅水与底色读取模板材质权重，泥滩浑浊、沙滩清澈、岩岸骤深。
- 湖泊套用 24 种预制轮廓、14 种湖床与河流连接段，湖心岛按 7 套岛形逐宏观格抽签，格边界内收并淡出。
- 深海孤立格套用 20 种岛形模板，3D 与舆图共用同一高度采样。
- 2m 地形网格的水平面与冰面按 2cm 干湿等值线裁切，岸边波浪随屏幕水深自适应衰减。

###  湖河冻融

- 由绝对气候日经一阶热滞后得到水体有效温度，再用冷暖度日积分求冰厚与冰质：浅湾、近岸、小水面先冻，深水与大湖晚冻，春季先腐后化。
- 冰厚与承重分离：新薄冰脆，化冻旧冰即使较厚也弱。悬空单元可被踩碎、跳碎或落地击穿，破洞同时撤掉渲染与碰撞，人会真的落水；破洞状态随存档持久化，重新从 0 结冰。
- 浮冰与碎冰共用固定实例池，不承重、不加载区块。

###  天气与降水

- 25 档天气、风速 0–5 驱动植物与旗帜摆动；晴天与雾天各有独立的雾距曲线。
- 逐日降水场推进水汽、季节雨热与雨日判定，3D 天气与舆图雨云雷达共用同一场数据。
- **20 类气候区与季风**：结合年均温、冬季温度与干湿条件划分气候区，舆图气候层和植被选种共用同一分类；季风影响季节雨热与云层运动。
- 植物按基准温度与稳定哈希正态错峰换季（±15 日），同一物种不在同一天集体变色。

###  天文与天象

- 十五颗轨道星体、星座与星云，日月按世界时间、地理与黄赤交角运动。
- 公历 / 农历（定朔置闰）/ 元历三历并轨，观星舆图显示日食偏全环食区与月食可见区。
- 流星、流星雨、周期彗星与日月食按确定性窗口生成，`/world.astra events` 查看预报。

###  存档与界面

- **五槽存档**：1 快速 + 3 手动 + 1 自动。存档页可选择手动槽、改名、导出，或复制为「悠游」副本。
- **应用与恢复**：界面倍率可调 0.5×–4×，新装默认 1×。应用布局或画质预览后有 12 秒确认时间，取消或超时便恢复。Windows 支持窗口、无边框和全屏。
- **OKLab 动态配色**：41 个颜色令牌运行时计算，`color-mix(in oklab, …)` 等价实现，自动按 WCAG 对比度下限压深文字色；主色可由玩家衣冠色接管，日/夜两套随系统切换。
- **界面语言**：内置简体中文、繁體中文和 English，日语由随包附带的语言包提供。外置语言包放在 `userdata/mods/l10n/`。

##  操作说明

| 操作 | 动作 |
| :--- | :--- |
| **W / A / S / D** | 行走；飞行时为水平移动 |
| **鼠标** | 转动视角（点击画面锁定指针） |

##  从源码构建

**Android**：安装 JDK 17、Python 3、Gradle 8.11.1、Android SDK 35、NDK 28.2.13676358 与 CMake 3.22.1，将 Gradle 加入 `PATH`，并设置 `ANDROID_HOME`。

```powershell
powershell -ExecutionPolicy Bypass -File build_android.ps1
```

脚本打包当前资源并生成 `obj/android/app-build/outputs/apk/release/app-release-unsigned.apk`。可用 `-Gradle` 指定 Gradle 路径、`-BuildRoot` 指定外部构建目录。安装前需要使用自己的 Android 发布密钥签署 APK；请保管密钥，以便后续覆盖升级。

**环境**：Windows 10 / 11 x64；Visual Studio 2022 或 2026（安装「使用 C++ 的桌面开发」工作负载）。无第三方依赖，无需包管理器。

```bat
build.bat
```

脚本会自动定位 `vcvars64.bat`、收集 `src/` 下的 C 源文件、编译 `app.rc` 图标资源，链接 8 个系统库，最终在仓库根目录产出 `qianlinchaguan.exe`，中间产物写入 `obj/`。请保留同级 `content/` 与模型贴图目录后运行。

编译选项为 `/O2 /fp:precise /std:c11 /utf-8 /W3 /MT`：静态链接 C 运行时，产出单文件绿色程序。

> `build.bat` 按常见安装路径查找 Visual Studio；若安装位置特殊，请在脚本 `:find_vcvars` 段手动指定 `vcvars64.bat`。

也可使用 Python 3 与 CMake 构建 Windows 版。CMake 至少为 3.22，并须支持所选 Visual Studio 生成器：

```powershell
cmake -S . -B obj/cmake -G "Visual Studio 18 2026" -A x64
cmake --build obj/cmake --config Release
```

Visual Studio 2022 对应生成器为 `Visual Studio 17 2022`。程序位于 `obj/cmake/Release/qianlinchaguan.exe`，配套资源位于 `obj/cmake/assets/`；将该目录内的资源复制到 exe 同级，或把 exe 放入资源目录后运行。

##  存档与设置

| 项目 | 格式 | 说明 |
| :--- | :--- | :--- |
| 世界容器 | `PACK` / `QLCG` v2 | 一个 `.sav` 内含 5 个槽位 |
| 槽体 | v23 | `QSV3` 槽头；地形改动、领地、行囊、探索、冰、天气与人偶等状态按段保存 |

| 设置 | `QLCGST10` | `userdata/settings.bin` 保存键位、视距、视角、植被密度、触控布局、配色和画质等偏好 |
| 地形 | v14 | 统一水文地形与定稿河道归档；旧档按可迁移条件转换 |

当前源码接受 Windows 的 v11–v23 槽体和 Android 的 v13–v23 槽体。旧档仍需通过地形和数据校验；迁移前后的存档会验证，原档保留为 `.legacy-N`。

##  常见问题

**启动黑屏 / 提示显卡不支持？**
Windows 需 OpenGL 3.3 Core，可先更新显卡驱动并在本机桌面运行。Android 需 Android 10 或更新版本，以及 OpenGL ES 3.0。

**界面缺字或字形不对？**
Windows 可将字体 `ttf/otf` 放入 `userdata/mods/fonts/`，在设置页点「重新扫描」，无需重启。

**存档在哪、能否备份？**
Windows 的存档在 `userdata/saves/`，复制 `userdata/` 可一起备份设置。Android 在存档页导出副本，再将副本保存到系统文件选择器提供的位置。

**为什么发布包里还有 `src/` 目录？**
`src/systems/world/model/` 下的四季贴图是运行时远景贴图资源，保留原相对路径可让发布包与源码树保持一致，直接构建即可运行。
